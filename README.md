# Interfaz de Inicio de Sesión Moderna con TTKBootstrap

## 📝 Descripción
Este proyecto es una aplicación de escritorio que implementa una interfaz gráfica de usuario (GUI) moderna y estilizada para un sistema de inicio de sesión (Login). Utiliza estilos avanzados para transformar los componentes tradicionales de la biblioteca gráfica nativa de Python en una experiencia visual contemporánea y atractiva.

## 🎯 Objetivo
El objetivo principal es diseñar un formulario de acceso seguro, intuitivo y estéticamente profesional utilizando las capacidades de diseño de **TTKBootstrap**:
* **Librería gráfica:** Aplica temas visuales modernos (oscuros o claros) sobre los widgets estándar de `tkinter`/`ttk` mediante hojas de estilo predefinidas.
* **Componentes de acceso:** Estructura de forma limpia los campos de captura de datos esenciales como la entrada de usuario, la máscara de seguridad para la contraseña y el botón de validación.

## 🚀 Aplicación y Notas de Arquitectura
Esta herramienta funciona como una plantilla de interfaz de usuario para proyectos locales o de escritorio que requieran autenticación de usuarios antes de permitir el acceso a sus módulos internos.

**Casos de uso principales:**
* **Aplicaciones de escritorio locales:** Pantalla de bienvenida para sistemas de inventario, punto de venta o administración local.
* **Prototipos rápidos:** Diseño veloz de maquetas de software que deban ejecutarse de forma nativa en sistemas operativos sin depender de un navegador web.

⚠️ **Recomendación Tecnológica para Nuevos Proyectos:**
Aunque este script demuestra con éxito el potencial de TTKBootstrap para modernizar interfaces antiguas, si vas a iniciar un proyecto de escritorio completamente desde cero, **se recomienda aprender y utilizar Flet**. 
* **¿Por qué?** Flet está basado en la arquitectura de Flutter, lo que permite crear aplicaciones nativas, multiplataforma (escritorio, web y móvil) mucho más interactivas, fluidas y con un paradigma de desarrollo moderno y reactivo.
